# Secure-Login-System

## Introduction
This project is a simple Secure Login System made using Python. It checks username and password for user authentication.

# Working
1. User enters username and password.
2. Program checks entered details.
3. If correct:
   Login Successful
4. Otherwise:
   Invalid Username or Password


   # Advantages
- Beginner friendly
- Lightweight project
- Easy to understand


# Limitations
- Fixed username and password
- No database connection


# Conclusion
This project helps understand basic secure login authentication using Python.



# How to Run

python secure_login.py
